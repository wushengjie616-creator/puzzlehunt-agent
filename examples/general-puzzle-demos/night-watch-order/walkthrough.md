# 最后一班守灯人：演示讲解

## 看到什么

卡片被明确说成散落，交接记录描述先后和“直接交给”。每张卡片还有 2–3 个灯标，题面称它们对应口令的敲钟拍数。铜盘“慢了三格”是尚未使用的异常。

## 竞争假设

1. 按题面列出的卡片顺序直接取字；这会浪费全部交接记录。
2. 先解唯一排班，再按灯标数量从各人口令取字。
3. 灯标也可能表示排序；但数量重复很多，无法形成完整次序，只适合作为局部索引。

## 最小可证伪测试

Moth 必在首位、Stag 必在末位；Crow–Hare 和 Lynx–Fox 是两个不可拆块，且 Hare < Owl < Lynx。七个位置刚好被唯一排成 `Moth, Crow, Hare, Owl, Lynx, Fox, Stag`，所以无需猜测平局。

## 联想到什么

按排班重排卡片后，灯标数量自然落在每个口令长度内。取出的 `ODQWHUQ` 仍不像器材，提示铜盘的“三格慢差”是第二层校正，而不是废话。

## 调用什么

用 `constrained_order` 证明排班唯一，用 `extract_nth` 按灯数取字，再用 `caesar_shift` 校正铜盘。

## 中间结果

唯一顺序是 `Moth → Crow → Hare → Owl → Lynx → Fox → Stag`。灯标取字得到 `ODQWHUQ`；铜盘比标准慢三格，所以退回标准表得到 `LANTERN`。

## 怎么验证

五条交接记录全部满足且排序唯一；七个灯标都有合法索引；校正后是七字母灯塔器材，符合题目问法和长度。答案为 `LANTERN`。
