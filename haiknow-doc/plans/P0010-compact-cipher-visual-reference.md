# P0010 · 紧凑密码图表、猪圈示意图、盲文与旗语

<!-- 一旦执行此 plan 即冻结；偏差只写到对应 task 的“与计划的偏差”章节，不回改本 plan -->

## 1. 目标与边界

- 把资料表改成桌面 10 列、窄屏 5 列的紧凑速查格；ASCII 同样使用短格，不再渲染宽表格。
- 凯撒与栅栏资料卡只保留规则和注意事项，不显示无意义的对照表。
- 猪圈密码缩小数据格，并展示一张由 GPT Image 生成、纯黑白、无装饰的 A-Z 示意图。
- 盲文以六点黑/白圆点绘制 A-Z 与 0-9；数字明确说明需要数字标志 `3456`。
- 新增旗语 A-Z，以发信者视角的双臂八方向小图和方向文字表达。

不改变密码转换 API、DeepSeek 链路、数独/数织/扫雷行为；不使用生成图作为可执行映射的唯一真相源。

## 2. 实施方案

1. 参考数据增加 `show_table`、旗语方向对和完整盲文数字表；凯撒/栅栏关闭表格。
2. 页面渲染器按条目类型选择紧凑网格或 GPT 猪圈图；ASCII 每格只显示字符、十进制、二进制和十六进制。
3. 盲文和旗语使用 DOM/CSS/SVG-like div 线条确定性绘制，保证数据可测、缩放稳定和无额外图片请求。
4. 静态资源路由允许项目内 `assets/pigpen-reference-gpt.png`，包数据包含 PNG。

## 3. 风险与验证

- 生成图中文字可能错误：已人工检查 A-Z 唯一性与点位；自动测试同时检查源数据，不让图成为算法 SSOT。
- 旗语左右视角易混：页面明确“面对发信者/发信者左手与右手”，方向数据以权威参考交叉核对。
- CSS 紧凑后可能难读：浏览器桌面和窄宽度截图检查，保留可访问的文字标签。
